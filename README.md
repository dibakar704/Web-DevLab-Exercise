# Programming for Web Development - I Laboratory

This repository contains my lab exercises (P1 to P13) covering terminal usage, Git and GitHub workflows, semantic HTML5, and modern CSS layout systems.

## Lab Modules & Exercises

### Module 1: Terminal, Git & GitHub (P1–P4)
- **P1:** Project folder setup and terminal navigation
- **P2:** Portfolio repository initialization and initial commit
- **P3:** Feature-branch Git workflow and Pull Requests
- **P4:** GitHub README documentation and version tags

### Module 2: HTML & CSS Foundations (P5–P9)
- **P5:** Semantic bio webpage
- **P6:** Full portfolio page structure using semantic HTML
- **P7:** Design tokens and typography system in CSS
- **P8:** Sticky navigation bar and card overlay using CSS positioning
- **P9:** Responsive navbar and card grid using Flexbox

### Module 3: CSS Layout Systems (P10–P13)
- **P10:** Portfolio header and footer using advanced Flexbox
- **P11:** Newspaper-style three-column layout with CSS Grid
- **P12:** Portfolio projects grid using advanced CSS Grid
- **P13:** Combining Flexbox and CSS Grid for a shared layout

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Custom Properties, Positioning)
- Git & GitHub
